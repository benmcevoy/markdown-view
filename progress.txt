## Codebase Patterns
- The project uses simple YAML frontmatter parsing (key: value pairs)
- Frontmatter is enclosed between --- markers
- The scanner strips frontmatter from displayed content but stores metadata
- NavigationItem.Frontmatter is a Dictionary<string, string> for simple key-value pairs
- The project targets .NET 10.0 with Markdig for markdown rendering
- Always check existing using directives before adding new ones
- Port 5000 may need to be freed before restarting the server
- Directory traversal prevention is implemented at the request path level
- Scanner correctly handles files without frontmatter (treats entire content as markdown)
- NavigationItem.Content should be trimmed of leading/trailing whitespace after frontmatter removal
- Security features are implemented in Program.cs including rate limiting, path validation, and request sanitization
- Static assets (CSS/JS) are served from wwwroot directory
